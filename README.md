# maxfilms-site-assets

CSS, JS and images for maxfilms.no, served through jsDelivr at a pinned commit:
`https://cdn.jsdelivr.net/gh/maxmedialab/maxfilms-site-assets@<commit>/css/style.css`

A push does not deploy. The site loads a pinned commit, so a change goes live only when the pin is bumped in GHL.
